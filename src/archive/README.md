# Archive

Scripts from earlier exploration that neither the thesis paper
(`docs/paper/paper_final.tex`) nor the deck (`docs/presentation/presi.tex`)
uses. They are kept for the record. Several are cited in
`docs/DISCOVERY_FINDINGS.md` and `docs/METHODOLOGY_REVIEW.md`, which document
checks and fixes made along the way.

Moved here from `src/<folder>/` on 2026-11-12, keeping the folder name
(`src/tda/x.py` is now `src/archive/tda/x.py`). The scripts were not edited.
Their paths assume the old location: each finds the repo root and its imports
(`tda_classifier`, `stuff_plus_calculator`) relative to its own folder. To run
one, move it back to its original folder first.
